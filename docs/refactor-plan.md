## 2. 何が問題か（今日踏んだバグから逆算）

### ① 首を動かす経路が5つある

```
つまみ / 踊り / キメのポーズ / 直接 move_head / beat_mode
```

**調停する場所がどこにもない。** 今日の重いバグはほぼ全部ここ発。

- pose ストリームが毎秒20回「正面」を送り、踊りを潰していた
- `beat_mode_start` が後から motion を有効にし、モード設定を上書きした
- キメのポーズと踊りの pitch 単位が食い違い、真下に張り付いた

→ **`HeadArbiter` を作り、角度を書ける場所を1つにする。**
   優先順位は つまみ > キメ > 踊り。誰も直接 `move_head` を呼ばない。

### ② 状態が散らばっている

```
pose.dance / pose.hold / led.enabled / led.swoon / led.flash_white
self.mode / _blinking / _torque_off / _knob_was / _silent_since / _hold_i
```

**「いま踊っているか」を1箇所で答えられない。** だから起動順序や
モード遷移で取りこぼしが出た（起動時に `set_mode` が素通りした件など）。

→ **`PerformerState` に集約**し、変更は関数経由のみにする。

### ③ 単位が暗黙

`pitch` が「絶対角度」なのか「45からの差」なのかが型に現れない。
**この1点に1時間溶かした。**

→ 型で分ける（`ServoAngle` / `AngleOffset`）か、最低でも関数名に入れる。

### ④ テストが1つもない

今日ここで拾えたはずのバグ：

- pitch のオフセット取り違え
- 置換が空振りして**振り付けが一度も入っていなかった**（3回）
- LEDフレームのフィールド名違いで728フレーム全捨て

→ **振り付けを純関数にすれば、実機なしでテストできる。**
   `dance_angles(bpm, t, groove, phrase) -> (yaw, pitch)` は副作用ゼロにできる。

### ⑤ 設定が全部CLI

40個の引数を毎回打ち直していた。会場で調整する運用に耐えない。

→ **`config.toml` に持たせ、CLIは上書きだけ**にする。

## 3. 目標の構成

```
app/dj/
  console.py      起動と配線だけ（100行以内）
  config.py       設定の読み込みとCLI上書き
  gateway.py      MCP接続・ツール呼び出し
  midi.py         MIDI → 意味のあるイベント（TurnKnob / PressPad / Play / Off）
  motion/
    arbiter.py    ★首の主導権を1箇所に。角度を書けるのはここだけ
    phrases.py    振り付け（純関数 + データ）
    poses.py      キメのポーズ
  led.py          模様（純関数）
  audio.py        拍・音量・リッスンチェック
  vision.py       顔検出
  performer.py    演出の決定（モード・表情・反応）
  state.py        PerformerState
tests/
  test_phrases.py 振り付けの角度が範囲内か、単位が正しいか
  test_led.py     フレームの形（kind/ts/colors）が仕様通りか
  test_groove.py  音量・確信度 → ノリ の対応
```

## 4. 進め方（イベントまで21日）

**★イベント前に大改修しない。** 動いているものを壊すリスクが釣り合わない。

| 時期 | やること |
|---|---|
| **いま〜9/29** | **触らない。** 設定を `config.toml` に出すだけ（これは低リスクで効果大） |
| 9/29 | イベント本番 |
| 9/30〜 | ①`HeadArbiter` → ②純関数化＋テスト → ③モジュール分割 の順 |

**順番の理由**：`HeadArbiter` が一番バグを減らす。
テストは純関数化しないと書けない。分割は最後でいい（動作に影響しないので）。

## 5. いま入れる価値があるもの（低リスク・高効果）

1. **`config.toml`** — 会場で調整した値が残る。CLI 40個を打ち直さなくてよくなる
2. **`--verify` フラグ** — 起動後に実機の角度を10秒測って範囲を表示する。
   「直したつもり」を潰す。今日いちばん効いたはずのもの
3. **デッドコード削除** — `pose_stream.py` は console.py に吸収済み

これだけなら半日で入り、本番のリスクを上げない。
