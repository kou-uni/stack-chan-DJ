## Phase 1 で必要な配線は、これだけ

```
Mac Studio ──USB-C──▶ スタックチャン（足側ポート）
```

以上。**1本だけ。**

| 項目 | 中身 |
|---|---|
| ケーブル | **データ通信対応の USB-C**。充電専用だと焼けない |
| 挿す場所 | **足の後方（ベース基板側）**。頭側は首が回って自分で抜く |
| 役割 | 給電 ＋ 書き込み ＋ シリアルログ |

これに加えて、配線ではないが必要なもの：

- **2.4GHz の Wi-Fi**（5GHz非対応。SSIDとパスワードを手元に）
- **スマホ**（`http://192.168.4.1` のキャプティブポータルで設定するため）

## DJ連携の配線 — 2系統あり、両方いる

**要件は4つ。音だけで済むのは1つだけ。**

| やりたいこと | 何で取る | 配線 |
|---|---|---|
| 音楽が流れると踊る・光る | **本体マイク**（`beat_mode`） | **不要**。空気を伝わる音で足りる |
| **つまみを回すと首が回る（yaw）** | **MIDI** | **DDJ-FLX2 → Mac に USB-C** |
| **別のつまみでうなずく（pitch）** | **MIDI** | 同上 |
| **ボタンで表情を変える** | **MIDI** | 同上 |

**MIDI は必須。** つまみの角度も、ボタンが押されたことも、音からは絶対に取れない。
`beat_mode` が担うのは1行目だけ。

```
DDJ-FLX2 ──USB-C──▶ Mac（gateway と同じマシン）──Wi-Fi──▶ スタックチャン
```

### 家での開発（いま）

**DDJ-FLX2 を Mac Studio に挿す。**
家では gateway が Mac Studio にいるので、同じマシンに DDJ があると `localhost` で完結する。
MacBook に挿したままだと、MIDI を読む場所と gateway が別マシンになって、経路が1つ増える。

### 当日

DDJ-FLX2 は MacBook に挿す。当日は MacBook が gateway なので、やはり同じマシンで完結する。
**「DDJ は gateway と同じ Mac に挿す」が通しのルール。**

## 任意：外付けLEDテープ（優先度は低い）

**M5Stack 純正 `A093`**（0.5m / 30LED / SK6812 / IP65 / ¥1,144）。
スイッチサイエンス `ssci.to/6914`。**HY2.0-4P ケーブル同梱**で追加購入は不要。

```
スタックチャン Port B（Grove / GPIO9）──▶ A093（30LED / 0.5m）
```

| | |
|---|---|
| ピン | 赤=VCC / 白=GND / 緑=データ |
| ⚠️ 電流 | **全開 5V@1.8A。Grove ポートからは取れない** |
| 対策 | ソフト側で明るさ上限（`--led-brightness 0.35`）。色付き3割なら 200〜400mA |
| レベルシフタ | **不要**（SK6812 は 3.3V データで動く） |

```bash
./.venv/bin/python app/dj/console.py --led-target port_b --led-count 30
```

Port B(GPIO9) と Port C(GPIO17) の2系統あり、各256個まで挿せる。
ただし**関門を越えるまでは箱を開けない**。本体12個のLEDだけでも拍同期の絵はできている。

## Phase 2 で足すもの（遠隔ワークベンチ）

```
Mac Studio ──USB-C────▶ スタックチャン（足側）
           ──USB──────▶ Webカメラ（本体に向ける）
           
スマートプラグ ──▶ USBハブの電源      ← 遠隔ハードリセット
```

- **Webカメラ**：首が振れたか外から目視する。音の確認が遠隔では一番難しいので、LEDの色で代用する
- **スマートプラグ**：自動リセットが失敗して固まったときの唯一の逃げ道

## 当日（9/29）の配線

Mac Studio は持ち出せない。

```
iPhone ──USB──▶ MacBook ──内蔵Wi-Fiで2.4GHz APを立てる──▶ スタックチャン
                    ▲                                        ▲
              DDJ-FLX2（USB-C）                     モバイルバッテリー
```

- iPhone は **USBテザリング**で回線を供給するだけ（Wi-Fiテザリングは使わない）
- **スタックチャンは Wi-Fi でしか繋がらない。** USBは給電だけ
- **モバイルバッテリー必須**（内蔵550mAhは持たない）
- **DJ卓の上には置かない。** 振動する。別の台に固定

## 置き方の注意

- サーボが動くので、放っておくと**机の端まで寄っていく**。台に固定する
- **電源が入った状態で首を手で回さない。** ハードが壊れる
- 落下は遠隔では直せない。周囲を空ける
