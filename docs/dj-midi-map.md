# DDJ-FLX2 MIDI マップ

すべて1つずつ実測して確定（2026-09-08）。推測は書かない。
機械可読版は `app/dj/mapping.json`。

## つまみ → 首

| 用途 | 種別 | ch | 番号 | 入力範囲 |
|---|---|---|---|---|
| **首を左右に回す（yaw）** | CC | 6 | **23** | 0〜127 |
| **うなずく（pitch）** | CC | 0 | **15** | 0〜127（128種すべて確認） |

```bash
./.venv/bin/python app/dj/pose_stream.py \
  --yaw-cc 23 --yaw-ch 6 \
  --pitch-cc 15 --pitch-ch 0
```

gateway 側から購読させる:

```
stackchan_follow_pose_stream(action="start", url="ws://127.0.0.1:8770/")
```

## 操作系

| 用途 | 種別 | ch | 番号 | 挙動 |
|---|---|---|---|---|
| **PLAY（左デッキ）** | Note | 0 | **11** | **DJモードON**。トグルにしない（セット中に何度も押すため） |
| **MASTER（中央・ロゴ下）** | Note | 6 | **99** | **DJモードOFF**。トグルにしない（押しっぱなしで使う人がいる） |

## パッド → 表情

**#4〜#7 の隣接4枚。** 指の移動が最小になる配置。

| パッド | 表情 | 使いどころ |
|---|---|---|
| Note ch7 **#4** | `happy` | 曲が乗ってきたら |
| Note ch7 **#5** | `surprised` | ドロップ・キメ。暗い箱で一番変化が見える |
| Note ch7 **#6** | `embarrassed` | 人に触られたとき・褒められたとき |
| Note ch7 **#7** | `sad` | 曲を止めたとき・フェーダーを下げたとき |

**`idle` にはパッドを使わない。** 表情は **4秒で自動的に `idle` に戻す**。
押しっぱなしで顔が固定されるのを防ぎ、落差で「反応した」ように見せるため。

## 使える表情（実物の enum）

`idle` / `happy` / `thinking` / `sad` / `surprised` / `embarrassed` / `off`

`off` はアバターを消して、下の xiaozhi-esp32 の画面（WiFi設定・OTA・設定）を出す。演出用ではない。

## 見送ったもの

**`say()` による決め台詞。** 無料で使えるエンジン（VOICEVOX / edge-tts）はあるが、
別プロセスの起動が要るのと、**押してから鳴るまで間がある**のでリアルタイム性で表情に劣る。
やるなら事前生成した音声を鳴らす方が本番では堅い。実機で遅延を測ってから判断する。

## 分かっていること

- **14bit の MSB/LSB ペアで来る。** `#n` と `#n+32` が同数で届く（0/32・7/39・11/43・19/51・31/63）。
  **MSB 側だけ使えばいい**
- 絶対値か相対値かは**値の並び方**で見分ける。
  絶対値＝多数の異なる値をなめらかに登る／相対値＝64付近に張り付くか 0と127 を往復する
- パッドは `ch7 #0`〜`#7` の8つ。ボタンらしきものが `ch0 #11` `ch0 #12` にもある
- つまみ側で動いたのは `ch0 #0` `ch0 #7` `ch0 #11` `ch0 #15` `ch0 #19` `ch1 #19` `ch6 #23` `ch6 #31`

## 測定の失敗例

pitch を最初「全可動域で 0〜64」と記録したが**誤り**。
本人が中央付近で止めた区間を、こちらが全可動域と解釈した。再測定で 0〜127 を確認。

**教訓：可動端に達したかどうかは、測定側からは分からない。**
「端まで動かした」という申告を確定条件にせず、
**0 と 127 の両方が観測されたこと**をもって全可動域とみなす。
