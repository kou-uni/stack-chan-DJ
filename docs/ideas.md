## （元メモ）2026-09-12 本人メモ：LED と操作を結びつける

いま LED は「音に反応する」だけで、**触っても、つまみを回しても光らない。**
下の4つは、**別々の思いつきではなく1つの方向**を向いている。

> **入力があったら、必ず身体のどこかが応える。**

### 1. 撫でたら LED も派手に反応する

撫でられて照れる**と同時に**、LEDが七色にピカピカ光る。

- いま撫での反応は**顔と首だけ**（`app/dj/touch.py` の `TouchReactor`）
- LED は `presence` → `reconcile` 経由なので、**overlay と同じ仕組みで色を割り込ませる**のが素直
- ★ただし会話中の色の意味（`TALK_COLOR`）と競合する。**どちらが勝つかを先に決める**

### 2. つまみの値を LED でボリューム表示する

MIDI の 0〜127 を、30個のLEDの**点灯本数**で表す。

- 音量メーターのように見える
- ★「いま何を触っているか」が**手元を見ずに分かる**のが本当の価値

### 3. レコードをこすったら LED が激しく踊る

スクラッチに反応してキラキラする。

- 既存のパターン（`laser` / `sparks` / `strobe_hard`）を**入力から直接呼ぶ**
- ★音の解析を待たずに、**操作そのものに反応する**のが速くて気持ちいい

### 4. 割り当てていないボタン・つまみでも、必ず何か起きる

**1ボタン1アクションにしない。** 複数のボタンに同じ動き（頷く・見回す）を割り当てる。

> **触ったのに何も起きないと、人は「壊れている」と思う。**
> 割り当てていないボタンこそ、**何か返す**べき。

- いまは `mapping.json` に載っているものだけが反応する
- ★**既定の反応**を決めておいて、載っていない入力は全部そこへ流す
