言いたいことは1つ。「AIをDJする、AIとDJする」。

  • DJする … 素材は自分が作っていない。それでも選択と並びとタイミングに自分が出る

A　掴み（10分）— 説明より先に触らせる

言うことは最小。触らせる。順番に回す。1人ずつ手のひらに乗せてもらう。

やること起きること
手のひらに乗せる「思ったより軽いでしょう」
頭をなでる照れる・首をかしげる・LEDが七色に回る
続けて何度もなでる反応が変わる（照れる→慣れる→嫌がる）
曲を流す踊る。LEDが拍で光る。背中のスクリーンも同じ色で光る

★ここで一度、ゲージを上げる（バースト）

ドヤるためではない。「DJ台と繋がっている」に気づいてもらうため。

  何もしていない状態を見せる
     ↓  進行役がフェーダーを上げる
  会場が赤く染まる → 花火とCO2
     ↓  戻す
  「いま触ったのは、これです」と DJ台を指す

因果が見えないと、ただ派手なだけになる。 上げて、戻す。指す。

ここで言う3つ

  • 「置いてあるだけの時は、何もしていません」

待機は動かさない。この落差のほうが体験として強い（実測で「キョロキョロは不気味」）

  • 「反応の速さを覚えておいてください」 ← B で効く
  • 「同じ動きは二度しません」 振り付けは複数あり、長さも一定でない

注意

  • 電源が入った状態で首を手で回さない（ハードが壊れる）。回す前に必ず言う
  • 連続タップさせない

Aの合格条件：触った人が、自分から2回目を触る。

これが出なければ、何が動いていても負け。

① 構成（6分）— 中に AI は入っていない

  マイク・カメラ・タッチ  ──▶  実機  ──▶  Macの中の頭脳
  サーボ・LED・画面      ◀──        ◀──

実機は I/O ゲートウェイ。だから頭脳を差し替えられる。

今日いちばん持ち帰ってほしい考え方。

「中にAIが入っているロボット」だと思うと、買ったものが天井になる。

入口と出口だと思うと、頭脳は自分で選べる。

★実演：実機の Wi-Fi を切る。

  切る  → 止まる（顔も首もLEDも）
  戻す  → 何ごとも無く再開する
「これだけで全部止まります。中身は、この子の中に無いからです。」
言葉で10回言うより速い。

実機が受け取っているのは、角度と色の列だけ。

1秒に 首30回・色20回。意味は一切持っていない。

背中のスクリーンも同じで、流れているのは このロボット自身のソースコード。

実機のLEDと背景のLEDは、同じ30個の配列を映している。

★実演：LEDパッドを押す。 実機と背景が同時に変わる。
「作り直していないからです。同じ配列を2つに送っているだけ。」

② ファームの中身（7分）— MCPが入っている　★ここが選んだ理由

ファームは5つ調べた。選んだのは、MCPが入っているもの。

すぐ始められることそのままだと
出荷時すぐ喋る。速い声も画像も海外のクラウドへ。同意の動線が無い
自前構成（今日のもの）頭脳を選べる。外に出ない。AIと作れる会話は自分で組み直すまで戻らない

A で感じた「速さ」の理由がここ。 便利さは、どこかに繋がっていることで成り立っている。

けなす話ではない。知って使うのと、知らずに使うのは別、という話。

物理カメラカバーを小道具に使う。口上は privacy-notice.md

MCPとは — 道具の並べ方と呼び方だけを決めた規格

★実演：道具の一覧を出す。

  首を動かす      表情を変える      LEDを光らせる
  写真を撮る      タッチを読む      音を鳴らす
  …… 全部で 49個

この49個が、ファームの中で「道具」として並んでいる。

だから Claude Code が一覧を読んで、自分で選んで、呼べる。

取扱説明書と製品が、同じものになった。
「どう動かすか」を読んで、コードに書き写す工程が丸ごと消えた。

だから、AIと作るのに向いている

これは感想ではなく、選定理由。

普通のファームMCPが入っているファーム
何ができるかドキュメントを読むエージェントが一覧を取得する
どう呼ぶか自分でコードを書く名前と引数が決まっている
試すまでビルドして焼くその場で呼べる

「AIに任せられる範囲」が、ファームの作りで決まる。

ここを選び間違えると、何を作るにも先に翻訳作業が要る。

④ DJの接続（6分）— ★見せ場。人間が入力になる

DJ機材は USB で Mac に刺さっているだけ。

流れているのは「番号と、0〜127の値」それだけ。

  つまみを回す  →  CC ch6 #23 = 94
                      ↓  読み替える
                    首の角度 / LEDの本数 / 光量
触るもの実機背景スクリーン
つまみ首が回る・LEDが点灯本数でメーターになる—

音量フェーダー赤く激しく点滅・首が大きく揺れる会場が赤く染まり、花火とCO2

③ スタックチャンがサブ講師に立つ

AIについて学ぶ会で、AIが教える。この構造自体が教材。

  • 講師は1人なのに質問は同時多発する。待っている間、手が止まる
  • 短く答えて、深い話は「手順は君のエージェントが持ってる」と振る

★会話の始め方：頭をなでる。

A で撫でたら「照れた」。D で撫でたら「聞く顔になる」（首を上げてこちらを見て、LEDが緑）。

同じ動作で違うことが起きる。 これが B の「同じハードが別人になる」の実演になる。
緑＝聞く は配布物に書いてある色。紙と身体が一致する。
誰かが話している間は緑のまま ＝ 順番待ちが言葉なしで解決する。

⚠️ Dに入る前に、1回だけ予告する。

「さっきと同じところを触ってみてください。さっきと違うことが起きます。」

予告しないと、照れると思った人には「壊れた」に見える。予告すると、驚きは大きくなる。

⚠️ 踊りと会話は同じマイクを取り合う。 切り替えはブロックの切れ目で進行役が1回。
