設計図 — どの機械が、
何を持っているか

4つの機械が関わります。ロボット、Mac、iPad、そして外から開くためのトンネル。 どれが何を担って、データがどちらへ流れるかを、1枚ずつ開けていきます。

01 — 論理構成4つの機械の役割

ロボットの中にAIは入っていません。入口（マイク・タッチ）と出口（首・声・光）だけを持っています。 考えることも、色を決めることも、絵を描くことも、全部 Mac の中です。

DEVICE

スタックチャン

I/O ゲートウェイ。判断は一切しない

  • 入口 — マイク／頭のタッチ（3ゾーン）／カメラ
  • 出口 — サーボ2軸（首）／LCDの顔／内蔵LED／外付けテープ30粒／スピーカー
  • 受け取るのは角度と色の列だけ。意味は持たない
  • 電源を切ると表情もタッチ設定も消える（毎回入れ直す）

ESP32 / Wi-Fi 2.4GHz → ws:8775

BRAIN

Mac（当日は MacBook）

頭脳・演出・配信。ほぼ全部ここ

  • gateway — 実機との窓口。聞き取り（STT）もここ
  • console — 踊り・LED・首・モード。状態を持つ唯一の場所
  • Ollama — 考える（gemma3:4b）
  • VOICEVOX — 声を作る（話者14）
  • 背景サーバ — iPadに配る／操作パネルを配る

8767 MCP ／ 8770 首30Hz ／ 8771 LED20Hz ／ 8779 画面・パネル ／ 11434 頭脳 ／ 50021 声

SCREEN

iPad

ブラウザだけ。アプリも配線も無い

  • URLを開くと HTML 1枚が落ちてくる
  • 毎秒20回、いまの状態がWebSocketで届く
  • 絵はその場で描く（動画ではない）
  • 落ちても開き直すだけで戻る

Safari → ws:8779/ws

CLOUD

外に出るもの

AIは1つも使っていない

  • 外部のAI・音声認識・音声合成 … ゼロ
  • 使うのはトンネル1本だけ（外から操作パネルを開くため）
  • 当日、会場ではそれも要らない（同じLANで完結）
  • 声も画像もこの部屋から出ない

cloudflared → 8779（任意・当日は未使用）

03 — DJ盤つまみ1つ1つが、何になるか

特別な操作画面はありません。MIDIの数字を、角度・色・光量に読み替えているだけです。 DJが普段やる手つきが、そのまま演出になります。

操作MIDI実機で起きること背景で起きること
首のつまみCC ch6 #23 首が左右に回る／LEDが点灯本数で値を出す—
うなずきのつまみCC ch0 #15 首が上下する／同じくメーター—
表情パッド ×4Note ch7 #4–#7 happy surprised embarrassed sad—
LEDパッド ×11Note ch9 #0–#7 ／ ch1 #11,#12,#88 模様が変わる（13種）同じ色が柱とグリルとリングに出る
PLAYNote ch0 #11DJモードON。音に反応し始める照明が点く
MASTERNote ch6 #99OFF。待機に戻る照明が落ちる
右レコード（擦る）CC ch1 #34 LEDが白く速く刻む下からスポットライトが立ち上がり、左右に振れる
音量フェーダーCC ch1 #19 70%〜 赤く激しい点滅／首が大きく揺れる 会場が赤く染まる → 100%で花火・CO2
未割当のつまみ・ボタン— 必ず何か起きる（頷き＋LED）—
押して無反応だと、その人は「壊れている」と思って離れます。 だから割り当てていないボタンでも、必ず身体のどこかが応えるようにしてあります。

04 — LEDの連動1本の配列が、4箇所に出る

背景の光は「それらしく作った絵」ではありません。 実機のテープに送っているのと、まったく同じ30個の色の列を、画面も受け取っています。

消えているときは、画面の光も消えます。 「いま出している色」の判定を1箇所に置いてあるので、 実機が暗いのに画面だけ光る、が起きません。

05 — 表情顔は、誰が決めているか

顔は7種類。パッドで直接変えるものと、状態から自動で決まるものがあります。 ぶつかったときは、強い方が勝つように順番が決めてあります。

強さきっかけ顔期限
1（最強）つまみを触っている向いている方向離して2秒
2頭をなでた照れる／慣れる／嫌がる（6種から選ぶ）3秒
3聞いている／喋っているthinking happy会話が終わるまで
4サビを検出驚く短く
5歓声を検出喜ぶ短く
6表情パッドhappy surprised embarrassed sad4秒で戻る
7（既定）モードDJ中は happy／待機は idle—
一時的な顔には、必ず期限を付けてあります。 期限のない上書きは消し忘れが起きて、パッドを押しただけで顔が固定されます。

スマホでURLを開くだけ。アプリは要りません。カメラは既定でオフです。
