# 配布物 — 単体で開けるページ

**原本は `src/`、配れる形がここ。** 原本を直したら必ず走らせる。

```bash
./.venv/bin/python scripts/pack-page.py          # 全部
./.venv/bin/python scripts/pack-page.py firmware # 1枚だけ
```

## 中身

| ファイル | 中身 | 狙い |
|---|---|---|
| `shinkou.html` | 当日の進行（90分・ブロックごとに渡すもの） | 進行役が見る |
| `tsukutta-mono.html` | **作ったもの全部**。6系統＋土台。10日・161コミットの棚卸し | G4・G5 |
| `dj-hajimekata.html` | **おまけ**。自分のDJ機材でやる手順 | 家に帰ってから（G3・G5） |
| `firmware.html` | ファーム5つの比較と、選んだ理由 | **聞いておいてよかった**（G2） |
| `haisenzu.html` | 当日の配線と、落ちたときの退避 | 人に説明できる（G4） |
| `sekkeizu.html` | 論理構成・DJ盤・LED・表情・リモコンの対応 | **もらってラッキー**（G5） |
| `shippai.html` | **失敗カタログ**。35件を6つの型に。なぜそうしたくなるかとセット | **他では聞けない**（G2・G4） |

## 3通りの開き方

1. **ファイルをダブルクリック** — 電波が無くても開く
2. **同じLANのブラウザ** — `http://<MacのIP>:8779/p`（一覧）
3. Artifact のURL（手元に無いとき）

★**書体だけは Google Fonts から落ちます。** 電波が無いと代替の書体になりますが、
中身は全部読めます（図も動きます）。

## 決めごと

- **2箇所を手で書かない。** 直すのは `src/` だけ
- ページを足したら `src/` に置いて、走らせるだけ（一覧は自動で増える）
- `/p/` は**名前しか受け取らない**。パスを外から組み立てさせない
