## ★作品としての仕掛け（進行役だけが知っていること）

**これはデモではなく、作品として作っている。**

> ```
>    インプット          AI          アウトプット
>     （DJ）                         （ロボット）
>       │                                │
>    人間がAIに                  AIが人間の世界に
>    自分らしさを持ち込む          身体を持って出てくる
>       └───── 出会う場所は、この机の上 ─────┘
> ```
> 出典：`docs/requirements.md` 0-0（2026-09-09 本人が言語化）

**言いたいことは1つ。「AIをDJする、AIとDJする」。**

- **DJする** … 素材は自分が作っていない。それでも**選択と並びとタイミングに自分が出る**
- **AIと** … 相手は画面の中ではなく、**机の上に身体を持って出てきて、踊っている**

### ★最初に言わない。最後に気づかせる

**冒頭で「これはAIをDJする作品です」と言ったら、気づきが死ぬ。**
前半は**一度も名指ししない。** 伏線だけ置いて、F で初めて図を出す。

| | 置く伏線 | 名指ししない言い方 |
|---|---|---|
| **A** | 身体がある。触ると応える | 「置いてあるだけの時は、何もしていません」 |
| **B④** | **人間の手つきが、そのまま演出になる** | 「特別な操作画面は1つもありません」 |
| **C** | 作り手も、穴に落ちながら選んできた | 「これは僕の場合の選択です」 |
| **D** | **参加者自身が入力になる**（DJ機材／エージェントに渡す） | 「自分ならどのつまみに何を割り当てますか」 |
| **F** | **回収。ここで初めて図を出す** | 下記 |

### なぜUIUXを積んできたか（Fで言う）

撫でたら応える。光が実機と画面で一致する。灯体は揺れない。連結部は光らない。
**「使えること」ではなく「そこに居ること」を作っている。**

> **AIに、身体と作法を与える試み。**
> 物理法則を守るのは、リアルに見せたいからではなく、
> **嘘があると、そこに居ることにならないから。**

## A　掴み（10分）— 説明より先に触らせる

**言うことは最小。触らせる。順番に回す。1人ずつ手のひらに乗せてもらう。**

| やること | 起きること |
|---|---|
| 手のひらに乗せる | 「思ったより軽いでしょう」 |
| 頭をなでる | 照れる・首をかしげる・**LEDが七色に回る** |
| **続けて何度もなでる** | **反応が変わる**（照れる→慣れる→嫌がる） |
| 曲を流す | 踊る。**LEDが拍で光る。背中のスクリーンも同じ色で光る** |

### ★ここで一度、ゲージを上げる（バースト）

**ドヤるためではない。「DJ台と繋がっている」に気づいてもらうため。**

```
  何もしていない状態を見せる
     ↓  進行役がフェーダーを上げる
  会場が赤く染まる → 花火とCO2
     ↓  戻す
  「いま触ったのは、これです」と DJ台を指す
```

**因果が見えないと、ただ派手なだけになる。** 上げて、戻す。指す。

### ここで言う3つ

1. **「置いてあるだけの時は、何もしていません」**
   待機は動かさない。**この落差のほうが体験として強い**（実測で「キョロキョロは不気味」）
2. **「反応の速さを覚えておいてください」** ← B で効く
3. **「同じ動きは二度しません」** 振り付けは複数あり、長さも一定でない

### 注意

- **電源が入った状態で首を手で回さない**（ハードが壊れる）。回す前に必ず言う
- 連続タップさせない

**Aの合格条件：触った人が、自分から2回目を触る。**
これが出なければ、何が動いていても負け。

### ① 構成（6分）— 中に AI は入っていない

```
  マイク・カメラ・タッチ  ──▶  実機  ──▶  Macの中の頭脳
  サーボ・LED・画面      ◀──        ◀──
```

**実機は I/O ゲートウェイ。だから頭脳を差し替えられる。**
**今日いちばん持ち帰ってほしい考え方。**

「中にAIが入っているロボット」だと思うと、**買ったものが天井になる。**
**入口と出口だと思うと、頭脳は自分で選べる。**

**★実演：実機の Wi-Fi を切る。**

```
  切る  → 止まる（顔も首もLEDも）
  戻す  → 何ごとも無く再開する
```

> **「これだけで全部止まります。中身は、この子の中に無いからです。」**
> 言葉で10回言うより速い。

**実機が受け取っているのは、角度と色の列だけ。**
1秒に **首30回・色20回**。意味は一切持っていない。

背中のスクリーンも同じで、流れているのは **このロボット自身のソースコード**。
**実機のLEDと背景のLEDは、同じ30個の配列**を映している。

> **★実演：LEDパッドを押す。** 実機と背景が**同時に**変わる。
> 「作り直していないからです。同じ配列を2つに送っているだけ。」

### ② ファームの中身（7分）— MCPが入っている　★ここが選んだ理由

**ファームは5つ調べた。選んだのは、MCPが入っているもの。**

| | すぐ始められること | そのままだと |
|---|---|---|
| 出荷時 | **すぐ喋る。速い** | 声も画像も海外のクラウドへ。**同意の動線が無い** |
| 自前構成（今日のもの） | 頭脳を選べる。外に出ない。**AIと作れる** | 会話は自分で組み直すまで戻らない |

**A で感じた「速さ」の理由がここ。** 便利さは、どこかに繋がっていることで成り立っている。
**けなす話ではない。知って使うのと、知らずに使うのは別、という話。**

> 物理カメラカバーを小道具に使う。口上は [privacy-notice.md](privacy-notice.md)

#### MCPとは — 道具の並べ方と呼び方だけを決めた規格

**★実演：道具の一覧を出す。**

```
  首を動かす      表情を変える      LEDを光らせる
  写真を撮る      タッチを読む      音を鳴らす
  …… 全部で 49個
```

**この49個が、ファームの中で「道具」として並んでいる。**
だから Claude Code が**一覧を読んで、自分で選んで、呼べる。**

> **取扱説明書と製品が、同じものになった。**
> 「どう動かすか」を読んで、コードに書き写す工程が丸ごと消えた。

#### だから、AIと作るのに向いている

**これは感想ではなく、選定理由。**

| | 普通のファーム | MCPが入っているファーム |
|---|---|---|
| 何ができるか | ドキュメントを読む | **エージェントが一覧を取得する** |
| どう呼ぶか | 自分でコードを書く | **名前と引数が決まっている** |
| 試すまで | ビルドして焼く | **その場で呼べる** |

**「AIに任せられる範囲」が、ファームの作りで決まる。**
ここを選び間違えると、**何を作るにも先に翻訳作業が要る。**

### ③ 作り方（6分）— 線で繋いで、話しかけて作る

**ここが「私もやってみたい」に一番効く。**

```
  Claude Code  ──▶  MCP  ──▶  USB / Wi-Fi  ──▶  実機が動く
   日本語で頼む      道具49個                    首・撮影・LED・表情
```

**★実演：その場で打つ。**

```
  「右を向いて、写真を撮って」
     ↓
  実機が首を振り、撮った画像が返ってくる
```

**これが開発の実体です。** コードを書く前に、まず会話で動く。
動いてから、**繰り返したいものだけコードにする。**

### ここで言う3つ

1. **最初に線で繋ぐ。** Claude Code から叩けるようにするのが一番先
2. **会話で試してから、コードにする。** いきなり書かない
3. **踏んだ穴はエージェントに渡す。** 人間が覚え直さない（→ C・D へ）

### ④ DJの接続（6分）— ★見せ場。人間が入力になる

**DJ機材は USB で Mac に刺さっているだけ。**
流れているのは「**番号と、0〜127の値**」それだけ。

```
  つまみを回す  →  CC ch6 #23 = 94
                      ↓  読み替える
                    首の角度 / LEDの本数 / 光量
```

| 触るもの | 実機 | 背景スクリーン |
|---|---|---|
| **つまみ** | 首が回る・LEDが点灯本数でメーターになる | — |
| **パッド** | 表情が変わる・LEDの模様が変わる | **同じ模様が同時に出る** |
| **レコードを擦る** | LEDが白く速く刻む | **下からスポットライトが立ち上がる** |
| **音量フェーダー** | 赤く激しく点滅・首が大きく揺れる | **会場が赤く染まり、花火とCO2** |

**★特別な操作画面は1つも無い。**
**DJが普段やる手つきが、そのまま演出になっている。**

> **これが今日の合言葉そのものです。**
> 素材は自分が作っていない。それでも、**選択と並びとタイミングに自分が出る。**
> **アレンジは創作だと、DJ文化がとっくに証明している。**

**割り当ては設定ファイル1箇所。** 変えれば、手つきが変わる。
**「自分ならこのつまみに何を割り当てるか」を、D で実際に触って考えてもらう。**

→ 📄 **[自分のDJ機材でやる](../docs/pages/dj-hajimekata.html)** を渡す（おまけ・家に帰ってから）

## D　手を動かす（25分）— 渡し方を覚えてもらう

**このブロック自体がメッセージ。**

```
  AIにドキュメントを読ませる   ← 素材を入れる
  AIに作業をさせる            ← 回してもらう
  人間は選ぶ・混ぜる・止める   ← 統制側に立つ
```

### ① リポジトリを渡す（10分）　→ 📄 **ガイドエージェント** ／ 📄 **始め方の地図**

**大きな手順は6つ。** 出荷時で遊ぶ → バックアップ → **アンバインド** → 焼く →
gateway を起動 → 作り込む。**止まるのはアンバインドと焼くの間。**
「一度、喋らなくなる」ことを知ってから始める。


1. QRを配る
2. 各自の Claude Code に読ませる
3. **ガイドエージェントが立ち上がる**

**手順は人間に渡さない。エージェントに渡す。人間が覚えるのは「渡し方」のほう。**
私が踏んだアンチパターンは、もう中に入っている。
**同じ穴に落ちる前に、渡してある状態から始められる。**

持っていない人は、進行役が操作するところを見て模擬体験する。

### ② 二本立てで進める（15分）

| | 誰が | 何を |
|---|---|---|
| **黙々派** | 自分で進めたい人 | エージェントと文字で対話しながら、自分の企画を詰める |
| **話す派** | 話したい人 | **DJ機材を触って、アイディアを広げる** |

**★DJ機材はここで触らせる。** 「自分の入力が身体になる」を手で試すと、企画の種になる。
つまみを回せば首が動く。擦れば光が走る。**Cブロックの「人間は統制側」が体で分かる。**

### ③ スタックチャンがサブ講師に立つ

**AIについて学ぶ会で、AIが教える。この構造自体が教材。**

- 講師は1人なのに質問は同時多発する。**待っている間、手が止まる**
- 短く答えて、深い話は「**手順は君のエージェントが持ってる**」と振る

**★会話の始め方：頭をなでる。**
A で撫でたら「照れた」。D で撫でたら「**聞く顔になる**」（首を上げてこちらを見て、LEDが緑）。

> **同じ動作で違うことが起きる。** これが B の「同じハードが別人になる」の実演になる。
> 緑＝聞く は配布物に書いてある色。**紙と身体が一致する。**
> 誰かが話している間は緑のまま ＝ **順番待ちが言葉なしで解決する。**

⚠️ **Dに入る前に、1回だけ予告する。**
> 「さっきと同じところを触ってみてください。**さっきと違うことが起きます。**」

予告しないと、照れると思った人には「壊れた」に見える。**予告すると、驚きは大きくなる。**

⚠️ **踊りと会話は同じマイクを取り合う。** 切り替えはブロックの切れ目で進行役が1回。

## F　返す（7分）— 集める前に返す／そして、回収する

### ① 返す（3分）

**まず本人に返す。それから同意を取る。**

1. その日の質問の傾向から、**「あなたのDJスタイル」を診断して返す**
2. **情報が足りなければ「評価対象外」と正直に言う** ← 占いとの決定的な差
3. **今後に生かしてよいかを訊く。同意した分だけ受け取る**

> **同意の順序が逆になっているのが要点。**
> 「集めさせて → 使わせて」ではなく「**あなたに返す → よければ共有して**」。
> B で批判した「同意の動線が無い」と、対になる実演。

→ 📄 **原価と日数の実データ**（★未作成。いくら・何日でここまで来たか）

### ② ★回収（4分）— ここで初めて、図を出す

   インプット          AI          アウトプット
    （DJ）                         （ロボット）
      │                                │

   自分らしさを持ち込む          身体を持って出てくる

```

**進行役は説明しない。順番に指すだけ。**

  右を指す   「踊っていたのが、右です」
  真ん中     「あいだにいるのが、AIです」
  机を指す   「出会った場所は、この机の上でした」

**そして本人ではなく、スタックチャンに言わせる。**

> **「今日、あなたたちは僕をDJしていました。
> 　そして僕は、あなたたちとDJしていました。」**

### 最後のひとこと（言い切る）

> **素材は、自分が作ったものでなくていい。**
> **選ぶ順番と、混ぜ方と、止めるタイミングに、その人が出ます。**
> **それを創作と呼んでいいことは、DJ文化がとっくに証明しています。**
>
> **だから、型紙にしないでください。**
> **今日のこれは、僕の場合のアレンジです。**

### 締め

**その日に起きたことを織り込んだスピーチ。**（録音 → 文字起こし → 台本 → 実機が喋る）

| 実機が切れた | 「**いま実機とMacの接続が切れました。**実機は入口と出口だけなので、繋ぎ直せば戻ります」 |
| 会話が遅い | 「**いま、この机の上のMacが考えています。**外に出していないぶん、正直です」 |
| 踊らない | 「**音が拾えていません。**会場の音量と、マイクの距離の問題です」 |
| 背景が止まった | 「**ブラウザを開き直すだけで戻ります。**動画ではなく、その場で描いているので」 |

保険：**デモ録画を手元に。** 最悪は出荷時ファームに戻せば単体で喋る。
