## A　触る（15分）— 説明より先に体験

**順番に回す。1人ずつ手のひらに乗せてもらう。**

| やること | 起きること |
|---|---|
| 手のひらに乗せる | 「思ったより軽いでしょう」 |
| 頭をなでる | 照れる・首をかしげる |
| 前に立つ | こっちを向く |
| **曲を流す** | **踊る。LEDが拍で光る** |

### ここで言う3つ

1. **「置いてあるだけの時は、何もしていません」**
   待機は動かさない。**この落差のほうが体験として強い**（実測で「キョロキョロは不気味」）
2. **「反応の速さを覚えておいてください」** ← B で効く
3. **「同じ動きは二度しません」** 振り付けは複数あり、長さも一定でない

### 注意

- **電源が入った状態で首を手で回さない**（ハードが壊れる）。回す前に必ず言う
- 連続タップさせない

## B　種明かし（15分）— 物理 ＋ ファーム

**プライバシーを独立コーナーにしない。** ファーム選択の話として語る。
**怖い話ではなく、判断材料にする。**

### ① スタックチャンは「物理 ＋ ファーム」でできている

**中に AI は入っていない。実機は I/O ゲートウェイ。**

```
  マイク・カメラ・タッチ  ──▶  実機  ──▶  ネットワーク  ──▶  頭脳
  サーボ・LED・画面      ◀──         ◀──              ◀──
```

**だから頭脳を差し替えられる。** ここが今日いちばん持ち帰ってほしい考え方。

### ② ファームを比べる

| | すぐ始められること | そのままだと |
|---|---|---|
| 出荷時 | **すぐ喋る。速い** | 声も画像も海外のクラウドへ出る。**同意の動線が無い** |
| 自前構成 | 頭脳を選べる。外に出ない | 会話は自分で組み直すまで戻らない |

**A で感じた「速さ」の理由がここ。** 便利さは、どこかに繋がっていることで成り立っている。

> 物理カメラカバーを小道具に使う。詳細は [privacy-notice.md](privacy-notice.md)

### ③ 入れ替えるとどうなるか

**Claude Code から、PCに繋いだ実機を経由して設定していく。**
実際に踏んだ関門を2つ見せる（6桁のコード／消えない設定）。

**★ゴールは「完成させること」ではなく「始められること」。**

## C　渡す（10分）— 人間がDJ、AIが演者

**このブロック自体がメッセージ。**

```
  AIにドキュメントを読ませる   ← 素材を入れる
  AIに作業をさせる            ← 回してもらう
  人間は選ぶ・混ぜる・止める   ← 統制側に立つ
```

**その場で全員にやってもらう。**

1. リポジトリのURLを配る（QR）
2. 各自の Claude Code に読ませる
3. **ガイドエージェントが立ち上がる**

**持っていない人は、進行役が操作するところを見て模擬体験する。**

> **手順は人間に渡さない。エージェントに渡す。**
> **人間が覚えるのは「渡し方」のほう。**

私が踏んだアンチパターンは、もう中に入っている。
**同じ穴に落ちる前に渡してある状態から始められる。**

## D　もくもく／ディスカッション（25分）

**二本立て。黙々を強制しない。** Bar に集まる意味は人と話せること。

| | 誰が | 何を |
|---|---|---|
| **もくもく派** | 自分で進めたい人 | **エージェントと文字で対話**しながら、自分の企画を詰める |
| **ディスカッション派** | 話したい人 | **人間同士**で「こんなことできないか」を話す |

**★スタックチャンがサブ講師として稼働する。**

- 音声で相談できる。**DJが鳴っていないので、音が通る唯一の時間帯**
- **短く答える。** 深い話は「手順は君のエージェントが持ってる」と振る
- 受付と振り分けをする先生。全体を見て、誰に何を渡すか判断する

進行役は貼り付かない。**詰まった人を見つけて回る。**

## E　ピッチ（15分）— 発表項目は2つだけ

```
  ① 自分は何をやろうと思ったか
  ② どこで詰まったか / 何が分からなかったか
```

**★②を発表項目にすることで、質問の収集が体験の一部になる。**
別の仕組みが要らない。

---

## F　返す（10分）— 集める前に、返す

**まず本人に返す。それから同意を取る。**

1. その日の質問の傾向から、**「あなたのDJスタイル」を診断して返す**
2. **情報が足りなければ「評価対象外」と正直に言う** ← 占いとの決定的な差
3. **今後に生かしてよいかを訊く。同意した分だけ受け取る**

> **同意の順序が逆になっているのが要点。**
> 「集めさせて → 使わせて」ではなく「**あなたに返す → よければ共有して**」。
> B で批判した「同意の動線が無い」と、対になる実演。

**当たったように感じたら、なぜそう感じるかまで説明する。**
ここまでやると、診断が教材になる。
